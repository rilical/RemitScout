# Sprint 3 Provider Intake Matrix

## Coverage tiers
- Corridors are assigned to Tier 1, Tier 2, or Tier 3 based on provider_count, allowed_b2b, success_rate, and freshness.
- No static corridor list. Scheduler reads corridor tiers from the coverage policy output.
